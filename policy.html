Use learning tools responsibly

Usage Policy

These guidelines help keep Code Academy useful, safe and focused on learning. They apply to lessons, AI tools, code, generated media and any community features that are available.

1. Learning integrity

Use Code Academy to understand concepts and practise skills. AI help may be useful for explanations and examples, but learners should make a genuine effort to understand the material and follow any rules set by their school, teacher, course or examination authority. Do not misrepresent AI-generated work as independent work when disclosure is required.

2. Responsible use of AI tools

  • Review AI-generated answers, code and calculations before relying on them.
  • Ask for explanations and examples that help you learn rather than blindly copying answers.
  • Do not use the tools to create scams, phishing messages, malware, abusive content or instructions intended to harm people.
  • Do not attempt to bypass safety limits, usage controls or provider restrictions.
  • Do not submit passwords, private API keys, confidential source code or sensitive personal information in prompts.

AI results can be wrong or incomplete, and tools may have usage quotas or be temporarily unavailable.

3. Security and code

Do not upload or distribute code intended to steal credentials, damage systems, bypass access controls or access accounts without permission. Only run example code in environments you trust, understand any requested permissions and avoid running unreviewed scripts on your main device. Report suspected vulnerabilities responsibly through the project support channel rather than exploiting them.

4. Community conduct

If community, sharing, comments or other user-to-user features are available, be respectful. Harassment, threats, bullying, impersonation, hate-based abuse, spam and publishing another person's private information are not acceptable. Use reporting or support options where available; do not retaliate against other users.

5. Copyright and generated content

Submit only material you own or have permission to use. Do not upload copyrighted course material, images, books or code in violation of the owner's rights. Generated answers or images may resemble existing material; check usage rights and applicable licence terms before distributing generated work publicly or commercially.

6. Privacy and personal safety

Share as little personal information as possible. Do not publish a home address, phone number, passwords, private credentials, payment information, school timetable or sensitive records. Younger learners should use appropriate parental or guardian supervision wherever required.

Read the Privacy Policy to understand how account information and content submitted to optional AI features may be handled.

7. Enforcement

Misuse may result in content removal, restrictions on a feature or account, or referral to a relevant service provider or authority where appropriate and lawful. The response will depend on the nature of the activity, available evidence and applicable requirements. We may update these guidelines as features evolve.

8. Questions or concerns

Contact the developer through the Code Academy project repository. Avoid posting private data or security credentials in public discussions. See also the Terms of Service.

This policy is a working draft and should be reviewed against the app's actual community and moderation features before publication.
