About Code Academy

Code Academy is a coding education app designed to help learners explore programming concepts, practise through examples and questions, and use study tools to support learning. It is intended to make the learning journey more organised and approachable for beginners and developing programmers.

Depending on the current release, the app may include programming courses such as HTML, CSS, JavaScript, Python and React, plus additional tracks. Feature names, course availability and AI providers can change as the application evolves.

1. Getting started

  1. Open the Code Academy app or select Open Code Academy if the app is already deployed alongside these public pages.
  2. Create an account or sign in using one of the authentication options currently enabled in the app.
  3. Open the course or learning section and select a topic you want to study.
  4. Read the lesson, review its examples, and complete available practice activities.
  5. Use profile and progress tools to review saved activity where those features are enabled.

If you are not ready to sign in, you can browse this documentation, the homepage, the Privacy Policy, the Terms and the Usage Policy without an account.

2. Courses and lessons

Course pages organise learning into topics and lessons. A lesson may contain explanations, example code, images or resources, and knowledge-check questions. Available course tracks can include:

  • HTML: webpage structure, semantic elements, forms and related fundamentals.
  • CSS: styling, layout, responsive design and visual presentation.
  • JavaScript: programming fundamentals, interactions and browser logic.
  • Python: syntax, variables, control flow, functions and other supported fundamentals.
  • React: component-based interface development and related concepts.

These examples are descriptive topic areas, not a promise that every track or every lesson is available in all releases. Follow the course list in your deployed app for the current catalogue.

3. Practice, quizzes and progress

Practice activities help reinforce what you have studied. Depending on the course, the app may offer quizzes, coding challenges, checkpoints, XP or point rewards, levels, streaks, certificates or other progress indicators.

Read question wording carefully and review explanations where available. A displayed score or progress indicator is intended as a learning aid; it is not necessarily an official qualification or examination result.

4. AI learning tools

Some releases may include a Smart AI Tutor, maths assistance, question generation or other AI-powered tools. These features can help explain a concept, provide an example, suggest practice questions or give a starting point for further study.

  • Ask focused questions and provide only the context needed to answer them.
  • Ask for step-by-step explanations when you need to understand a method.
  • Check generated code and calculations before relying on them.
  • Do not enter passwords, private API keys, payment information or confidential personal data.

AI features require a working internet connection unless a specific offline capability is provided. They may have usage limits, provider quotas and periods of unavailability. See the Privacy Policy for information about content submitted to AI features.

5. Other study tools

Depending on the deployed version, Code Academy may also provide a study planner, notes, saved code, a profile, community tools, image generation, question generation or reminders. Use the controls shown in your version of the app; not every tool is guaranteed to be enabled.

When a feature saves information, use the in-app controls to manage it where available. Keep your own backup of important notes and code rather than relying on a single copy.

6. Account access and privacy

Some features require you to sign in. If Google sign-in is available and you choose it, Google may return the basic profile information you authorise, such as your name, email address and profile image. Code Academy uses that information to authenticate you and support your profile. The app does not need access to Gmail or Google Drive for ordinary sign-in.

Read the Privacy Policy before signing in, and review the Terms of Service. The pages in this public information pack do not require authentication; other app pages may require an account.

7. Troubleshooting

Sign-in does not complete

Check your internet connection, confirm that the correct sign-in method is enabled, and retry in a supported browser or the current app version. If an error continues, include the error message and steps to reproduce it when requesting support, but never share passwords, tokens or secret keys.

A course or feature does not open

Return to the app's course menu and open the item again. Ensure you are using the latest deployed version and that required files have been published alongside the app.

An AI feature does not respond

Check connectivity and try a shorter request. AI tools may be temporarily unavailable, rate-limited or out of quota. Do not repeatedly submit the same request if a previous request may still be processing.

Saved progress appears missing

Confirm that you signed in with the same account and that connectivity has returned. Offline changes may not sync until the device reconnects, if that feature is supported by the current version.

8. Support and feedback

For questions or bug reports, use the Code Academy GitHub repository. Include the page name, expected behaviour and steps to reproduce the issue. Remove personal information from screenshots and logs, and never publish credentials or private API keys.

This guide is an overview of the intended learning experience. It is not a guarantee that every described optional feature is enabled in every deployed build. Keep this documentation aligned with the actual release.
